Esse repositório contem os códigos de Arduino e a planilha de Excel para a montagem e a execução de um carrinho controlado por Arduino associado a um equipamento de registro do movimento, o que permite estudar os diferentes tipos de movimentos da cinemática.





Dicionário de arquivos:

Sonar\_Excel.ino -> programa do Arduino que controla o sonar e coleta os dados para a construção dos gráficos no Excel

programas\_carro.rar -> arquivo comprimido contendo os códigos do Arduino que controla o carrinho; como é um programa em "abas", todos os arquivos precisam estar na mesma pasta ao abrir o programa na IDE do Arduino

carro.xlsm -> planilha do Excel que envia os comandos para o carrinho se movimentar, registra os dados e plota alguns gráficos





Para conseguir enviar os comandos usando a planilha, é necessário habilitar a função de macros do Excel: https://support.microsoft.com/pt-br/office/vba/enable-or-disable-macros-in-microsoft-365-files
