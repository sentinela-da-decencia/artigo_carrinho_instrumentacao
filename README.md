Esse repositório contem os códigos de Arduino e a planilha de Excel para a montagem de um carrinho controlado por Arduino associado a um equipamento de registro do movimento, o que permite estudar os diferentes tipos de movimentos da cinemática.





Dicionário de arquivos:

Sonar\_Excel.ino -> programa do Arduino que controla o sonar e coleta os dados para a construção dos gráficos no Excel
